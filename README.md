# breast-cancer-classification
# 🩺 Breast Cancer Classification Using Machine Learning

##  Project Overview

This project focuses on building a Machine Learning model to classify breast tumors as **Malignant** or **Benign** based on medical diagnostic features.

The project includes data preprocessing, exploratory data analysis, model training, and performance evaluation to identify the most suitable classification model.

---

##  Objective

The main objective of this project is to develop a Machine Learning classification model that can predict whether a breast tumor is:

*  Malignant (Cancerous)
*  Benign (Non-Cancerous)

based on the features available in the dataset.

---

##  Dataset

The dataset contains various diagnostic features related to breast cancer tumors, such as:

* Radius
* Texture
* Perimeter
* Area
* Smoothness
* Compactness
* Concavity
* Symmetry

The target variable represents the diagnosis of the tumor.

##  Machine Learning Models

The following classification algorithms can be used and compared:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree Classifier
* Random Forest Classifier
* Support Vector Machine (SVM)

---

##  Model Evaluation

The models are evaluated using classification metrics such as:

* Accuracy Score
* Precision
* Recall
* F1-Score
* Confusion Matrix

---

##  Results

The trained Machine Learning models are compared based on their performance metrics to identify the model that provides the best classification performance.

The final model can predict whether a tumor is **Malignant or Benign** based on the input diagnostic features.
